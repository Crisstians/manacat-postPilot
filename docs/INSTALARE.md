# Instalare PostPilot pentru angajați

PostPilot este aplicația Manacat pentru crearea rapidă a postărilor de produs pe rețelele sociale.

## Descărcare

1. Deschide pagina de release GitHub: [Releases](https://github.com/Crisstians/manacat-postPilot/releases)
2. Descarcă versiunea cea mai recentă:
   - **Mac**: fișierul `.dmg`
   - **Windows**: fișierul `Manacat PostPilot Setup x.x.x.exe`

## Instalare pe macOS

1. Deschide fișierul `.dmg`
2. Trage **Manacat PostPilot** în folderul **Applications**
3. Deschide aplicația din Launchpad sau Applications
4. Dacă macOS afișează avertisment de securitate:
   - mergi la **System Settings → Privacy & Security**
   - apasă **Open Anyway** pentru PostPilot

## Instalare pe Windows

1. Rulează fișierul `.exe`
2. Apasă **Next** și apoi **Install**
3. Lasă bifată opțiunea de shortcut pe Desktop (recomandat)
4. Deschide aplicația din Desktop sau Start Menu

## Actualizări automate

După prima instalare, PostPilot verifică singur update-urile la pornire.

Dacă apare mesajul **„Actualizare descărcată”**:
1. Apasă **Repornește acum**
2. Aplicația se va deschide cu versiunea nouă

Nu este nevoie să reinstalezi manual la fiecare versiune.

## Suport

Dacă instalarea eșuează, contactează administratorul IT Manacat și trimite:
- sistemul de operare (macOS / Windows)
- versiunea OS
- captură de ecran cu eroarea
